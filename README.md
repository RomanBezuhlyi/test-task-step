# Test Task

Тестовий проєкт на Vite (HTML, CSS, JavaScript).

## 🚀 Demo

https://romanbezuhlyi.github.io/test-task-step/

## 🛠️ Tech stack

- Vite
- HTML5
- CSS3
- JavaScript (ES Modules)
- iMask
- Fancybox

## 📦 Install

```bash
npm install
```

## ▶️ Dev

```bash
npm run dev
```

## 🏗️ Build

```bash
npm run build
```

## 🌐 Deploy (GitHub Pages)

```bash
npm run deploy
```

## ⚙️ Notes

При локальному запуску шлях до зображень відрізняється для Fancybox.

| Environment   | Path                          |
| ------------- | ----------------------------- |
| 🟢 Production | `assets/images/image.jpg`     |
| 🔵 Local      | `src/assets/images/image.jpg` |
